# 空间再编排 · 公用工作版

P1模型审阅候选，入口 `/review/p1/`。原装配、单一主楼候选、阶段3单独对照；局部树形与地面材质比较；整场待完善项与P033–P035现场依据。

这不是正式完成模型或模拟系统。主楼网格保持来源；候选只调整装配可见性及对中。10株样板树沿用旧候选的平面落点，树高为照片估计。三块既有路面/绿地替换材质，轮廓不变。历史运行时剪裁与调色未复刻。底层构件归属与道路衔接待核对。

## 运行

Node >=20。`npm ci`、`npm run build`、`npm start`。默认10000端口，可设PORT/HOST。Render自动部署main。

Three.js固定0.185.1，构建时复制必要模块。两份GLB以gzip保存，服务端按GLB路径返回Content-Encoding:gzip。服务器只开放明确列出的页面/资产；旧业务API返回410，不包含历史数据库、上传入口或密钥。

source-assembly来源：stage3资产asset_a98b0182ed4e与SKP转换artifact_2dbc856e76e8及既有小道补件；候选元数据见review/p1/data.json。vegetation-library是独立程序化树形样板，不是现场扫描。原本机项目不参与构建，也不需要访问本机绝对路径。

历史准备页保存在上一提交；可用Git回退内容的新提交恢复。不改动独立Sites部署。
